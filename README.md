# Author App Releases

This is a public repository for distributing releases of the Author app.

**Latest Version**: [View Releases](https://github.com/BaseTales/author-releases/releases)

## Auto-Updater Feed

Apps use the following URL to check for updates:
- **Feed URL**: https://basetales.github.io/author-releases/appcast.xml

## Contents

This repository contains:
- Release binaries (DMG files)
- Sparkle appcast.xml for auto-updates
- GPG public key for signature verification

**Note**: The main source code is in a private repository.
